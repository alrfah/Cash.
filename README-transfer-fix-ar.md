# إصلاح حوالات المستخدمين

كان المستخدم ينفذ تحديث أرصدة مباشرة من المتصفح، بينما قواعد Firebase تسمح بذلك للمشرف فقط. تم تغيير التنفيذ ليستخدم Cloud Function باسم `transferFunds`.

## النشر الإلزامي

من داخل مجلد المشروع:

```bash
cd functions
npm install
firebase deploy --only functions:transferFunds
```

بعد النشر:

1. امسح ذاكرة الموقع أو حدّث الصفحة.
2. سجّل خروجًا ثم ادخل بالحساب المستخدم.
3. جرّب الحوالة برقم حساب يبدأ بـ `SY` وطوله 26 خانة.

الدالة تتحقق من المرسل والمستلم والرصيد والعمولة، وتضيف العمولة إلى حساب المشرف وتلغي الخصم إذا فشلت الحوالة.
