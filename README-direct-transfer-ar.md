# نسخة التحويل المباشر

تمت إعادة تنفيذ التحويل عبر Realtime Database كما كان يعمل سابقًا، مع تثبيت حساب العمولة مباشرةً وعدم الاعتماد على Firebase Functions.

- لا يحتاج التحويل في هذه النسخة إلى نشر Cloud Functions.
- يتم التحقق من المرسل والمستلم وحساب العمولة مباشرةً.
- تظل العمولة مطبقة حسب العملة.
- دوال Firebase الموجودة داخل مجلد `functions` محفوظة للحماية الخادمية الاختيارية، لكنها ليست مطلوبة لتشغيل مسار التحويل المباشر الحالي.
