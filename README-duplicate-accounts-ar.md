# إصلاح تكرار الحسابات

- لا يمكن إنشاء حساب جديد إذا كان البريد الإلكتروني موجودًا في حساب حالي.
- تمت إضافة قفل ذري في `emailIndex` لمنع إنشاء حسابين عند الضغط المتزامن.
- يمنع التطبيق تغيير البريد الإلكتروني من الملف الشخصي، لأنه معرّف الحساب الأساسي.
- يعرض قسم الحسابات في لوحة التحكم تنبيهًا عند وجود سجلات بريد مكررة قديمة.
- لم يتم حذف السجلات القديمة تلقائيًا حتى لا يتم حذف حساب صحيح بالخطأ؛ يجب مراجعة التنبيه وتحديد الحساب الذي سيبقى.
