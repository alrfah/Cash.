# رفع تعليق الرصيد

من لوحة التحكم، عند فتح حساب مستخدم موقوف الرصيد، يظهر زر:

**رفع تعليق الرصيد ونقل المبلغ**

عند الضغط عليه:

- ينقل الرصيد المعلق بالدولار والليرة السورية والليرة التركية إلى الرصيد الفعال.
- يصفر حقول الرصيد المعلق القديمة والجديدة.
- يلغي `balanceSuspended`.
- يسجل عملية النقل في سجل الحركات.
- يعرض رسالة نجاح متناسقة داخل التطبيق.
