# إصلاح الرصيد والتحويل

- زر «تعزيز الرصيد» في لوحة التحكم يضيف المبلغ إلى الرصيد المعلّق فقط، ولا يغيّر الرصيد الفعال.
- تمت المحافظة على حقول `pending` و`pendingUsd/pendingSyp/pendingTry` للتوافق مع الحسابات الحالية.
- التحويل يتحقق بشكل منفصل من حساب المرسل والمستلم وحساب العمولة.
- تم تثبيت حساب العمولة للمشرف بدل البحث في جميع الحسابات، لتجنب خطأ قراءة بيانات المستلم.
- يوضح التطبيق الآن سبب فشل التحويل: حساب غير موجود، رصيد غير كافٍ، مشكلة صلاحيات أو مشكلة اتصال.

بعد الرفع إلى GitHub، انشر Firebase Functions عند استخدام النسخة الخادمية:

```bash
firebase use alrfah-cash
firebase deploy --only functions
```
