# Self-hosted font assets

These files are copied from the official Google Fonts distribution and are intended to replace the remote Google Fonts stylesheet after the parent agent updates the HTML. `fonts.css` keeps Arabic and Latin requests split and exposes Cairo's variable weight axis for the app's 400, 600, 700, and 800 declarations.

- **Cairo** — Google Fonts repository source: <https://github.com/google/fonts/tree/main/ofl/cairo>; Google Fonts CSS response used for the WOFF2 URLs: <https://fonts.googleapis.com/css2?family=Cairo:wght@400;600;700&family=Playfair+Display:ital,wght@1,700&display=swap>. License: [`OFL-Cairo.txt`](./OFL-Cairo.txt).
- **Playfair Display italic 700 (Latin subset)** — Google Fonts CSS response above. License: [`OFL-PlayfairDisplay.txt`](./OFL-PlayfairDisplay.txt).

No font files were generated or modified. The Cairo WOFF2 files are the official variable subsets; the Playfair file is the official static italic-700 Latin subset.
