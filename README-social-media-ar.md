# خدمة سوشيال ميديا

تمت إضافة أيقونة «سوشيال ميديا» إلى قسم الخدمات. تحتوي على روابط احترافية للمنصات:

- Instagram
- Facebook
- TikTok
- YouTube
- Telegram
- WhatsApp
- X
- Snapchat
- LinkedIn
- Threads

كما تمت إضافة زر لفتح موقع الخدمات المرتبط:

`https://prince.services`

لم يتم تعديل Firebase أو نظام الحسابات أو التحويلات. الملف المرفق يشرح API الخاص بالموقع، لكنه لا يحتوي على API Key؛ لذلك تم وضع رابط آمن للموقع بدل وضع مفتاح سري داخل الواجهة.
