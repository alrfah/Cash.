# تعطيل الخدمات وتحسين PDF

- جميع خدمات قسم الخدمات أصبحت غير قابلة للضغط.
- تظهر عبارة «سيتوفر قريبًا» على كل خدمة.
- لا يتم فتح نوافذ دفع أو خصم أي رصيد من الخدمات.
- تم تحسين إيصالات PDF عبر:
  - رسم الإيصال بدقة مضاعفة 2x.
  - استخدام PNG بدل JPEG لتجنب التشويش والضغط.
  - الحفاظ على أبعاد PDF نفسها مع مصدر صورة أعلى جودة.
- لم يتم تعديل Firebase أو الحسابات أو التحويلات.
