# تنظيف الحسابات المكررة

- يظهر زر «تنظيف المكررات» في لوحة التحكم عند وجود بريد مكرر.
- يحتفظ النظام بأقدم حساب/IBAN لكل بريد إلكتروني.
- يحذف السجلات الزائدة من `accounts` و`uidIndex` و`usernameIndex`.
- لا يتم حذف حساب المشرف تلقائيًا.
- السجلات التي لا تحتوي بريدًا لا تظهر في قائمة الحسابات.
- البريد الإلكتروني أصبح ثابتًا ولا يمكن تغييره من المستخدم أو المشرف.
- إنشاء الحساب الجديد يستخدم فحص البريد وقفلًا ذريًا لمنع التكرار.

يفضّل أخذ نسخة احتياطية من قاعدة البيانات قبل الضغط على «حذف السجلات الزائدة».
